# Focus_Timer

DeepWork Pro

A premium productivity and focus application inspired by modern SaaS tools like Linear, Notion, and Raycast.

DeepWork Pro is a fully responsive Pomodoro Timer web app built with pure HTML, CSS, and Vanilla JavaScript. It includes focus sessions, task management, statistics tracking, keyboard shortcuts, and localStorage persistence.

Features
Pomodoro Timer
Focus Mode (25 min)
Short Break (5 min)
Long Break (15 min)

Start / Pause / Reset / Skip controls
Productivity Dashboard
